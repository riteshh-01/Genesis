## 🌌 The Story of Genisis

Every developer has an origin story. **Genisis** is the living record of mine. 

This repository isn't just a random collection of files—it is a chronological timeline of my evolution in C++. It documents my exact path, step-by-step, from writing my very first, tentative `cout << "Hello World!";` to architecting and traversing complex, non-linear data structures like **Trees**.

Here, you will see the full progression:
🌱 **The Seed:** Grappling with basic syntax, loops, and conditions.
🌿 **The Roots:** Conquering the chaos of pointers, memory management, and arrays.
🪵 **The Trunk:** Structuring code through Object-Oriented Programming (OOP).
🌳 **The Branches:** Finally building out complex data structures like Linked Lists and Binary Trees.

---

## 🛠️ The Arsenal (What's Inside)

I am uploading my work in stages, reflecting my learning curve. Inside, you'll find:

* 🏁 **The Basics:** Printing statements, conditionals, loops, and pattern printing.
* 🧠 **Pointers & Memory:** The beautiful nightmare of raw memory management.
* ⚙️ **Object-Oriented Design:** Classes, inheritance, and encapsulation.
* ⛓️ **Linear Data Structures:** Arrays, Strings, Stacks, Queues, and Linked Lists.
* 🌳 **Non-Linear Data Structures:** Binary Trees, Binary Search Trees (BST), and traversals (Inorder, Preorder, Postorder).
